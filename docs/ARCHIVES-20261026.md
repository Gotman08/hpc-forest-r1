Cette publication ne désigne pas une version stable du moteur.

Chaque archive contient un manifeste. `SHA256SUMS.txt` contient les empreintes
des fichiers téléchargeables. Les archives publiées excluent les identifiants
OAuth et PriorLabs, les reçus d'autorisation, les poids des modèles, les
transcriptions brutes, les bases SQLite et les copies des répertoires Git.

Les résultats du 25 octobre sont historiques. Les nouvelles comparaisons sont
terminées : [UTF-8/Mandelbrot](../experiments/control-recovery-20261026/RAPPORT.md)
livrent huit codes sur huit ; [les six familles supplémentaires](../experiments/diversified-advisor-20261026/RAPPORT.md)
livrent onze codes sur douze, tous corrects aux contrôles réservés. Le conseiller
ne montre pas d'avantage sur ce lot diversifié. Le plan initial Popcount échoue
avant tout appel TabPFN et les temps Stencil sont fortement dispersés. Les
rapports séparent ces limites des corrections de continuité du contrôleur.

Les dossiers temporaires complets des quatre premières validations sont aussi
conservés dans une archive locale de 176 520 939 octets, empreinte
`4118efb53b2e95acbf1206af79a00a34a45ca239fbe9363d72b981c0b038f45d`.
Leur retrait de ROMEO ne concerne que ces copies temporaires sauvegardées.
Les campagnes de recherche historiques restent conservées.

Les temporaires de la validation réussie sont conservés séparément dans une
archive locale de 58 226 348 octets, empreinte
`b530d3b3fad88a6814c465a215eeea586091b4ef351c070d779c759498f11305`.
Les archives GitHub ont été retéléchargées et leurs empreintes vérifiées.
