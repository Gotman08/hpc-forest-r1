Reprises Forest sur ROMEO.
Les sources anciennes et nouvelles choisies avant la comparaison sont dans paired-*/.
Les archives campaigns/*/results.tar.gz contiennent les bases de recherche, dépôts Git et journaux ROMEO.
Les appels modèle locaux sont conservés sans configuration privée ni identifiants de transport.
Les archives payload.tar.gz contiennent le moteur et le protocole figés par campagne.
La suite de référence est fournie dans references/protected-suites.tar.gz.
Les programmes CPU requièrent ROMEO x86_64 / GCC 14.2 ; les GPU requièrent ARM / CUDA 12.6.3 / GH200.
Les chemins absolus historiques et les versions de dépendances sont consignés dans les plans.
Ne pas exécuter de calcul sur le nœud de login. Relancer dans une allocation SLURM adaptée.
Les wrappers ont été normalisés pour Linux. Les diagnostics d’échec sont conservés.
