---
name: inspecter-environnement
description: Vérifier les caractéristiques de l’environnement lorsqu’une décision d’optimisation dépend du matériel ou du logiciel disponible.
---

Réutiliser les caractéristiques déjà vérifiées dans le contexte de la campagne.
Inspecter les informations manquantes qui influencent l’optimisation envisagée.

Selon le problème, vérifier notamment :
- architecture et extensions disponibles ;
- compilateur, versions et options réellement utilisées ;
- bibliothèques, environnement d’exécution et ressources allouées ;
- organisation mémoire, accélérateurs ou communications.

Sur ROMEO, utiliser le MCP existant pour consulter ces informations et la
documentation du cluster. Respecter le périmètre de calcul autorisé.

Distinguer une capacité annoncée dans une documentation de sa disponibilité
effective dans l’environnement mesuré.

Rapporter les faits utiles, leur provenance et les incertitudes restantes.
Ne pas modifier la cible ou le protocole officiel pour favoriser un candidat.
